# ErfoNT v5.1.1 — iOS-inspired UI + Sync test build

این بسته برای قرار دادن مستقیم در ریشه‌ی مخزن GitHub و اجرای آزمایش کنترل‌شده آماده شده است.

## فایل‌ها
- `index.html` — سورس اصلی اصلاح‌شده
- `manifest.json` — تنظیمات PWA
- `sw.js` — Service Worker نسخه‌دار
- `icon-192.png` و `icon-512.png` — آیکن برنامه
- `firebase.rules.TEST-ONLY.json` — نمونه قوانین موقت تست (برای تولید استفاده نشود)
- `TEST_CHECKLIST.md` — چک‌لیست پذیرش

## انتشار
1. از نسخه فعلی مخزن یک کپی/branch پشتیبان نگه دار.
2. فایل‌های این پوشه را در ریشه‌ی مخزن قرار بده و Commit کن.
3. در GitHub از Settings → Pages، شاخه `main` و پوشه `/ (root)` را انتخاب کن.
4. بعد از انتشار، صفحه را با HTTPS باز کن. برای به‌روزرسانی PWA، در صورت دیدن نسخه قدیمی یک‌بار کش سایت را پاک کن یا سایت را در مرورگر ناشناس باز کن.

## اصلاحات نسخه 5.1.1
- نسخه نمایشی رابط کاربری به 5.1.1 به‌روزرسانی شد.
- صفحه قفل، دکمه‌ی بازیابی دارد که فقط صفحه ورود را باز می‌کند؛ دسترسی بدون رمز سازنده داده نمی‌شود.
- پس از ورود سازنده می‌توان از تنظیمات برنامه را دوباره فعال کرد.
- وضعیت همگام‌سازی دیگر صرفاً به‌خاطر ورود Firebase فوراً «همگام» اعلام نمی‌شود؛ ابتدا در حالت بررسی/ارسال قرار می‌گیرد و نتیجه تراکنش تعیین‌کننده است.
- فایل‌های لازم PWA همراه سورس قرار داده شده‌اند.

## Firebase: مهم
برای همگام‌سازی بین دستگاه‌ها، Anonymous Authentication باید در Firebase فعال باشد و قوانین Realtime Database باید اجازه‌ی دسترسی موردنظر را بدهند. آدرس دیتابیس داخل سورس باید با پروژه‌ی موردنظر تطبیق داشته باشد.

**امنیت:** نقش‌های برنامه در سمت کلاینت هستند. فایل `firebase.rules.TEST-ONLY.json` تنها برای تست کوتاه و کنترل‌شده است؛ هر کاربر احراز هویت‌شده، حتی کاربر ناشناس، اجازه خواندن و نوشتن داده مشترک را خواهد داشت. آن را برای استفاده واقعی منتشر نکن. پیش از عملیات واقعی، قوانین سمت سرور و احراز هویت مناسب طراحی شود.

## قبل از ورود داده واقعی
- از دیتابیس و از برنامه پشتیبان بگیر.
- ابتدا دو گوشی/مرورگر با داده آزمایشی تست شوند.
- ثبت، ویرایش و حذف تجهیز، تغییر موجودی، دستورکار، قطع و وصل اینترنت و بارگذاری مجدد صفحه آزمایش شود.
- موفقیت واقعی همگام‌سازی از این بسته به‌تنهایی قابل تضمین نیست؛ باید در Firebase و دو دستگاه بررسی شود.
